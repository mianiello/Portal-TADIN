Sobre el proyecto

Qué es TA-DIN y cómo está organizado el sistema.

TA-DIN es la documentación oficial que valida de punta a punta la arquitectura del proyecto: la comunicación entre la interfaz de usuario, la lógica del servidor y el almacenamiento de datos, sentando las bases para una futura certificación de procesos bajo la norma ISO 9001. El sistema se organiza en tres módulos que trabajan de forma integrada.

Módulos del sistema

Módulo A
W

Página web institucional

Carta de presentación digital de la empresa. Integra de forma embebida un formulario de Google para calificar prospectos y capturar datos de contacto.

Módulo B
R

Reloj biométrico

Sistema de hardware y software para el control de asistencia en tiempo real, que registra las entradas y salidas del personal.

Módulo C
H

Página de Recursos Humanos

Plataforma administrativa donde la empresa gestiona los datos de los empleados, revisa reportes de presentismo y administra la información interna.

N

Integración NFC

Las tarjetas NFC funcionan como tarjetas de presentación interactivas en reuniones y eventos comerciales: al acercarlas a un teléfono, el cliente potencial accede al instante al sitio web de TA-DIN o al formulario de contacto, sin usar papel y agilizando la conversión.
